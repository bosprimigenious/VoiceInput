# VoiceInput Windows 预览版

1. 完整解压 ZIP，运行 `VoiceInput.exe`。保留旁边的 `backend` 和 `models` 文件夹。
2. 在记事本或浏览器中点入输入框，按 `Ctrl + I` 开始录音，再按一次停止。
3. 等待转写。若文字没有自动进入输入框，右键系统托盘图标，选择“查看 / 复制最近文本”，手动粘贴。

包内自带 small 模型，可离线转写。首次启动无需另外安装 .NET。CPU 转写可能较慢；请等待托盘恢复就绪。转写中不要重复录音。

右键托盘打开设置，可选择中文、英文或自动语言，以及模型和提示词。medium 和 large-v3-turbo 需要自行下载对应模型；包内仅附带 small。

更新时退出旧程序，把新 ZIP 解压到新目录，再运行新目录的程序。旧目录保留用于回退。配置和最近文本位于 `%LOCALAPPDATA%\VoiceInput`，更换程序目录会继续使用原配置；自定义模型路径请自行确认有效。

没有麦克风时检查 Windows 桌面应用麦克风权限；快捷键被占用时先释放 Ctrl+I，再启动。转写成功会覆盖系统剪贴板，最近文本可从托盘恢复。

目标为 Windows 11 x64。未签名预览包可能出现 SmartScreen 提示。真人麦克风、热键和跨应用粘贴仍待实机验收，中文准确率及速度目标未评测；Windows 10 兼容性待验收。
